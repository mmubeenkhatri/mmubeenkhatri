## Selected Work

> Client work is described at architecture level — production code lives in private company repositories.

### LoanClod — Multi-Tenant Fintech Loan Platform
`Laravel` `JavaScript` `MySQL`

End-to-end loan lifecycle management for multiple financial institutions on a custom domain-based multi-tenant architecture. Built paperless documentation with e-sign integration, borrower task management, and an RBAC model spanning bank admins, supervisors and borrowers with a full audit trail.

**Sub-project — AI Document Classification Engine** `Python` `Tesseract OCR` `OpenAI API`
Led an OCR + LLM pipeline that maps uploaded documents to the correct loan tasks automatically. Bulk multi-document upload with automatic classification measurably cut manual loan-officer workload and sped up borrower onboarding.

### Dayzee Farms — Agri-Tech Livestock & E-Commerce Ecosystem
`Node.js` `React Native` `MySQL` `AWS EC2/S3` `Jenkins`

**Lead Developer.** Owned database architecture, API development and DevOps across web, mobile and admin platforms. Integrated MCB and Bank Alfalah payment gateways with 2FA on all clients, built a technician (artificial insemination) mobile app with order acceptance and real-time delivery tracking, and set up Jenkins CI/CD with automated deployments to AWS EC2.

### EnrichKids — Online Learning Platform
`NestJS` `TypeScript` `Next.js` `MySQL` `Stripe`

Designed and implemented the backend microservices architecture for an e-commerce-style e-learning product: course management, authentication, institution onboarding and Stripe payments — including a self-registration and course-publishing workflow that lets institutions list and sell courses independently.

### 340B Price Guide — Healthcare Drug Pricing Platform
`Laravel` `Python` `MySQL` `NLP`

Optimized critical SQL queries to make global search viable across large pharmaceutical datasets, re-engineered CSV bulk-import pipelines for drug names, pricing and classifications, and shipped an NLP-based conversational search that answers natural-language drug catalogue queries through a chat interface.

### Tradefindry — Interior Decorators & Vendors Marketplace
`Node.js` `AdonisJS` `React` `MySQL` `Firebase`

Two-sided marketplace with RESTful APIs, Firebase push notifications, and RBAC across admin, designer and vendor roles — plus designer editor boards, vendor catalogue, geolocation search and an event scheduler.
